# 深色辅助色与 Endfield 字体修正

## 设计方向

- **产品：** 开发者切换、操作和复制多风格 React 组件的工作台。
- **性格：** 准确、工程化、可检验。
- **环境：** 组件实验台；中性表面承载内容，品牌色用于真实控件与主题样本。
- **重点：** 真实组件的操作与选中状态，以及能准确对应主题输入的色板。
- **识别细节：** 保留 Endfield 的矩形控件、信号黄和预览方向切角。

Endfield 继续采用 `ark-ui` 的 `endfield / moderate` 契约。依据为该技能的 Endfield recipe、字体安全替代方案和既有项目设计，不引入另一套视觉方向，不复制官方字体或资产。

## 根因与修正

### 辅助色与容器不是同一个角色

品牌辅助色没有被改写。原深色算法将辅助色容器固定为 HCT tone 30，因此黄色、金色变成了棕褐色。下拉选中态、文字选区、tonal 按钮等共享这个容器，所以不能只给下拉菜单打补丁。

统一将自定义主题的深色辅助色容器改为 tone 80，并搭配 tone 10 文字；浅色保留 tone 90。Clean 原生深色配色使用相同的品牌色阶。其他风格的原生配色不变。

| 配色 | 辅助色原值 | 旧深色容器 | 新深色容器 |
| ---- | ---------- | ---------- | ---------- |
| 紫霄 | `#FCD34D`  | `#574500`  | `#EAC33E`  |
| 朱砂 | `#E1BB67`  | `#5B4300`  | `#E8C26D`  |

底部色板第二项原来展示 `--zx-tonal`，现在展示 `--zx-secondary`，标题也由 `Secondary container` 改为 `Secondary`。中性色阶预览继续展示表面、边界和文字，不将它误改成品牌色板。

### 展示字体与控件字体分工

Endfield 的窄体大标题属于 `ark-ui` 的预期表达，继续保留。控件原先在未安装 Space Grotesk 时优先回退到 macOS 的 DIN Alternate，造成整页标签也偏窄。现在使用 Space Grotesk → IBM Plex Sans → system-ui，并保留中文回退。

没有新增字体下载或依赖，因此本机安装的技术字体仍会影响最终字形；这不是对官方 Endfield 字体的精确复刻。

## Unslop 收尾检查

方法来自 Unslop，作者 Damir Sokolovsky（[@heydamir](https://x.com/heydamir)），CC BY 4.0。按 `references/signs.md` 与技能末尾清单，结合修正前后真实浏览器截图逐项自查。本轮为局部 polish，不重新设计整页，也未使用独立代理评审。

- **间距：** 保留既有 4px 节奏、目录行高和菜单触控尺寸；不引入额外留白或位移。
- **色彩：** 修复低明度暖色容器；原始品牌色与容器色角色明确；新增测试覆盖四套预设及极端输入。
- **图标：** 继续使用现有 Gravity 图标，没有 emoji、装饰性图标或新增图标集。
- **文案：** 修正色板角色名称，不增加空泛标题、宣传徽章或虚构信息。
- **字体：** 标题与控件各司其职；移除控件的 DIN Alternate 回退，不改变正文尺寸和字重。
- **布局：** 保留目录 → 当前组件 → 预览 → 代码的顺序；检查桌面、手机与 200% 等效宽度重排。
- **细节：** 色板与有效主题 token 一致；下拉选中、文字选区和焦点均保留清晰对比。
- **视觉：** 色彩集中在真实组件与主题样本；没有新增渐变字、光晕、玻璃背景或装饰素材。
- **动效：** 没有新增动效；沿用既有交互反馈和 reduced-motion 处理。

保留项：Clean 的紫黄配色是明确品牌资产，不因“去 AI 感”而删掉。朱砂自定义主题的中性色仍保留原算法的暖红倾向，本轮没有扩展成全站中性色重设计。

## 验证范围

- `pnpm lint`、`pnpm fmt:check`、`pnpm typecheck`。
- 主题生成及样式单元测试 **12 项通过**：品牌原值、浅深容器明度、文字对比至少 4.5:1、Clean 原生与自定义配色一致、生成样式入口同步。
- 浏览器定向回归 **11 项通过**：原生 Clean 与四套自定义预设的明暗选中态和辅助色色板、Endfield 字体分工、对比度、CSS 导出、保存恢复、系统明暗切换及嵌套浮层同步，以及菜单对齐、键盘取消和焦点返回、窄视口触控尺寸。
- Playwright 实图自查：1440px 桌面、390px 手机、720px 桌面 200% 等效重排，覆盖深色紫霄、朱砂、文字选区和 Endfield。
- `ark-ui` 启发式检查对共享基础、Endfield 适配层及 Demo 样式的组合输入为 **0 errors / 1 warning**；warning 为适配层中定义调色板字面量的启发式提示，不为消除提示而增加一层无用 token。

未跑生产构建、全量测试或全部 74 个组件的视觉遍历；窄视口重排不等同于操作系统级原生缩放验证。
