# React 风格目录：Clean、Endfield、鹤坡、鹤坡·室内、Minimal、Soft、Brutalist

`@zixiao-labs/ui-kits-react` 的七种风格复用相同组件和交互。用 `data-zx-style` 选择风格，用 `data-zx-color-mode="light"` 或 `"dark"` 选择该作用域的明暗。适配层均由 `@zixiao-labs/ui-kits-react/themes/<style>.css` 导出，与 `base.css` 一起使用；或使用一个 `styles.css`，无需额外加载适配层。完整示例见 [React 接入](usage.md)。

## 怎么选

| 风格                                            | 设计重点                       | 合适的场景               |
| ----------------------------------------------- | ------------------------------ | ------------------------ |
| [Clean](#clean--紫霄品牌与-material-启发)       | 紫黄品牌、圆润、清楚的容器层级 | 默认应用、品牌工具       |
| [Endfield](#endfield--现场工程)                 | 灰阶、信号黄、近直角           | 技术工具、运营控制台     |
| [鹤坡 Hepo](#hepo--鹤坡石白与黛青)              | 石白、黛青、浅木、宋黑分工     | 档案、阅读、文化工作台   |
| [鹤坡·室内](#hepo-interior--鹤坡室内红木与香槟) | 暖石白、红木、浅香槟、宋黑分工 | 展陈、接待、室内叙事     |
| [Minimal](#minimal--中性表面与深绿)             | 中性底、单一绿强调             | 表单、设置、日常内部工具 |
| [Soft](#soft--柔紫与轻阴影)                     | 柔紫、胶囊按钮、轻阴影         | 个人工具、引导、轻量流程 |
| [Brutalist](#brutalist--硬边界与酸黄绿)         | 硬边、硬阴影、等宽字体         | 实验工具、独立出版       |

颜色为原生适配层示意，不是让应用复制的色板。应用应读取语义 `--zx-*`，这样自定义配色和深色才能同步生效。局部换风格可以用来区分真正独立的工作区域，不要给同一流程的每颗按钮分配不同风格。

## Clean — 紫霄品牌与 Material 启发

`data-zx-style="clean"` · `themes/clean.css`。加载 `styles.css` 后，未设置风格的根作用域默认 Clean。

- **色彩：** 浅色近白紫 `#fef7ff`，深色炭紫 `#141218`。原生主色紫霄 `#8b5cf6` 和辅助色 `#fcd34d` 在两种模式保留；用专门的链接墨色和 tonal 填面做对比，不直接把实心填色当小号文字。
- **字体与形状：** Roboto 加中文黑体回退；胶囊按钮与 8 / 12 / 16px 容器圆角不同。按钮按压缩小到 97%，不是全局抬起所有面板。
- **应用：** 品牌工作区、新建流程和通用表单。让紫色承担主操作，暖黄留给辅助层级，已有真实紫色品牌不需要为 Taste 改色。只有这个适配层用 `--md-sys-*` 映射到 `--zx-*`；消费端写 `--zx-*` 即可。

## Endfield — 现场工程

`data-zx-style="endfield"` · `themes/endfield.css`。借鉴现场工程界面的视觉分工，不复制游戏标识、图片或界面。

- **色彩：** `#f2f2f0` 灰白与 `#191919` 炭灰分别承载明暗表面，信号黄 `#fffa00` 给主操作。浅色小指示、链接墨色和焦点在灰底上用深色，深色允许更多黄色状态标记。
- **字体与形状：** Space Grotesk / IBM Plex Sans 加系统文字回退。按钮直角、其他主要控件约 2px，清楚的边线比阴影重要；悬停不抬升，按钮按压下沉 1px。
- **应用：** 工具区、筛选栏、设备或运营面板。让真实字段和真实状态产生工程感；不编造遥测、不满屏铺黄，不拿过密的小号字冒充专业。

## Hepo — 鹤坡：石白与黛青

`data-zx-style="hepo"` · `themes/hepo.css`。以石白墙面、墨瓦与木作的明暗关系组织档案、图录或工作区。

- **浅色：** 石白 `#f8f7f3` 承载正文，黛青 `#3f5662` 表达主要操作，浅木辅助面 `#e8dfd1` 给次要操作和选中项。
- **深色：** 墨瓦 `#192227` 承载信息，浅水青 `#b8cccf` 配深字，浅木辅助面 `#d8c3aa` 仍明亮，不压成暗褐。
- **字体与形状：** 宋体作展示标题、黑体作长文和控件；细部 2px、控件 4px、较大容器 8px。保留细边线和 1px 按压反馈；默认不需要加纹样、抬升或背景光效。
- **应用：** 按年代看档案、检索馆藏、浏览有图注的长文。让标题、格线和真实内容先成立，再决定是否给局部加回纹、云雷纹或雷纹。

## Hepo Interior — 鹤坡·室内：红木与香槟

`data-zx-style="hepo-interior"` · `themes/hepo-interior.css`。独立适配层，不需要先导入鹤坡。

- **浅色：** 暖石白 `#f7f4ee` 为底，红木 `#82503d` 为主要操作，浅香槟辅助面 `#eee3cc` 给次要操作和选中项。
- **深色：** 暖炭灰 `#242321` 不把整页染褐；浅木操作色 `#e6b993` 和香槟辅助面 `#e7d7b9` 使用深字，实际检查默认、悬停、按压和选中。
- **字体与形状：** 沿用鹤坡的宋黑分工、细边和小圆角；和鹤坡的差异来自材质与配色，不是靠玻璃、金边或仿古木纹。
- **应用：** 室内展陈、场馆导览、接待或预约。同属鹤坡设计语言；用主任务选一套，而不是把两种主题叠在同一个业务模块。

## Minimal — 中性表面与深绿

`data-zx-style="minimal"` · `themes/minimal.css`。

- **色彩：** 浅色以白底和 `#25563f` 深绿为主，深色配 `#1a211d` 底和 `#a7d8b8` 浅绿。绿色用于操作和焦点，其余主要沿用基础层。
- **字体与形状：** 基础无衬线栈，按钮 6px、无额外装饰阴影。它不是新的控件密度或布局系统。
- **应用：** 表单、设置和需要长时间工作的内部工具。不通过极浅分隔线、过小文本或取消焦点环来换「极简」。

## Soft — 柔紫与轻阴影

`data-zx-style="soft"` · `themes/soft.css`。

- **色彩：** `#faf7ff` 浅底搭 `#71509a` 柔紫操作，深色 `#251e30` 底搭 `#d6b7f4` 淡紫操作。与 Clean 相比不以紫黄品牌对比为重点。
- **字体与形状：** 基础无衬线栈、胶囊按钮和轻阴影。表面分层仍通过填色和边线，不必把每个元素都变成胶囊。
- **应用：** 个人管理、首次引导、轻量操作；确认错误、选中和焦点在浅紫表面依然分明。不在柔紫之上再叠紫色光晕或低对比毛玻璃。

## Brutalist — 硬边界与酸黄绿

`data-zx-style="brutalist"` · `themes/brutalist.css`。

- **色彩：** 暖纸色 `#faf8ef` / 橄榄炭灰 `#24251e`，明暗都用酸黄绿 `#e5f36a` 作为操作填色，配深字。
- **字体与形状：** 等宽拉丁字与中文回退；按钮零圆角、2px 边线和 3px 硬偏移阴影辨识度强。共享组件不一定全部为直角，按各自 token 表现。
- **应用：** 独立出版、原型工作台、实验工具；用硬边界清楚区分动作，避免每一层都叠同样重的边和阴影。正文与密集表格按实际阅读长度验证。
